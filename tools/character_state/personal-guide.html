Assumptions

  • Run .\update-guides.ps1 and reload this page to use the latest local save. Add -Watch to regenerate when that save changes. The game may still have unsaved progress.
  • The estimate compares the guide's configured recipes in each level band, using your starting XP and bank stock. It carries spare materials between stages and adds the time to gather and craft missing supplies.
  • Expected yields and ingredient costs use averages for random outcomes. The model uses supported permanent modifiers from the save, keeps equipment fixed, and assumes ordinary crafting rewards.
  • Modifier coverage is partial. Rates start at the recipe's base values and use only the supported contributions listed below. The model excludes temporary, conditional, scaled, uncertain, and global bonuses, random side products, auxiliary training time, and time spent unlocking upgrades or operating the shop.
